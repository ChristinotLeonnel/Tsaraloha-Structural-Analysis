# ==============================================================================================
#  TSA — Tsaraloha Structural Analysis : raccourcis clavier (shortcut.txt)
# ==============================================================================================
#  Modifiez ce fichier puis enregistrez-le : TSA le relit aussitôt, sans redémarrage ni recompilation.
#  Une configuration invalide n'est jamais appliquée : la précédente reste active et l'erreur est
#  signalée dans la console de TSA. Éditeur intégré : Aide > Personnaliser les raccourcis (Ctrl+F1).
#
#  Colonnes : identifiant | raccourci(s) | état | par défaut | description
#   - identifiant : stable, ne pas modifier (les libellés de l'interface peuvent changer) ;
#   - raccourci(s) : « Ctrl+S », « Shift+F », « Num+7 », « F5 » ; plusieurs alias séparés par « ; » ;
#     suite de touches façon AutoCAD : « D, A » (D puis A) ; vide ou « aucun » : pas de raccourci ;
#     noms français acceptés : Maj, Suppr, Échap, Inser, Gauche, Droite, Haut, Bas, Entrée, Espace ;
#   - état : on (actif) ou off (désactivé, le raccourci est conservé pour plus tard) ;
#   - par défaut, description : pour information, ignorés à la lecture et régénérés.
#  Une commande absente du fichier garde son raccourci par défaut ; une commande inconnue est ignorée.
#  Deux commandes ne peuvent pas partager un raccourci, ni l'une commencer l'autre (« D » et « D, A ») :
#  la configuration serait refusée. Alt+F4 (quitter) reste géré par Windows.
#  Les champs de saisie gardent leurs touches (lettres, Ctrl+C, Ctrl+V, Ctrl+Z, Suppr…).
# ==============================================================================================
# format: tsa-shortcuts 1
