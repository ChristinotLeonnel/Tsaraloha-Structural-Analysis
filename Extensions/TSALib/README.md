# TSALib — TSA Engineering Library

Bibliothèque officielle d'ingénierie structurale et d'éléments de construction pour **TSA (Tsaraloha Structural Analysis)**.

## Architecture des répertoires

- `manifest.json` : Métadonnées officielles du package d'extension, version et dépendances.
- `Materials/` : Définitions JSON des matériaux (Béton, Acier, Bois, Sol, Maçonnerie, Verre, Aluminium).
- `Sections/` : Définitions des sections géométriques de calcul.
- `Profiles/` : Catalogues des profilés métalliques standardisés (IPE, HEA, HEB, UPN, Cornières, Tubes).
- `Cables/` : Câbles structuraux, torons et haubans.
- `Reinforcement/` : Aciers de ferraillage passif (B500B, etc.).
- `Prestressing/` : Systèmes et armatures de précontrainte (T15.7, barres de précontrainte).
- `Anchors/` : Dispositifs d'ancrage actif et passif.
- `Loads/` : Cas de charges types et combinaisons réglementaires.
- `Standards/` : Référentiels normatifs certifiés (Eurocodes EN 1990 à EN 1999).
- `Components/` : Composants et assemblages paramétriques.
- `Textures/` : Textures PBR externes (Albedo, Normal, Roughness) pour le rendu 3D OpenCASCADE.
